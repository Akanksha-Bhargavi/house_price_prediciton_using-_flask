# House Price Prediction using Flask

## **Project Description**

- This project predicts the price of a house based on various features like the number of rooms, location, area, etc. The web application allows users to input these features, and the system will predict the price using a pre-trained machine learning model. The entire application is developed using Flask for the web interface and Python for data analysis and machine learning tasks.

## **Installation**

- Clone the repository:
```bash
git clone https://github.com/Akanksha-Bhargavi/house_price_prediciton_using-_flask.git
```
## **Install dependencies**

```bash
pip install -r requirements.txt
```
## **Usage**

- Run the Flask application:
```bash
python app.py
```
- Open your browser and go to http://127.0.0.1:5000/.
- Enter house details and click Submit to see the predicted price.
  
## **Files Structure**

- app.py: Main Flask application.
- model.pkl: Trained machine learning model.
- templates/index.html: Input form for the user.
- static/style.css: Styling for the web page.
